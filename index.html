Tutorial

Langkah dari awal sampai asset siap dipakai di Roblox.

1

Daftar atau login

Di Home, buat akun atau masuk. Akun gratis mendapat 10 upload per hari.

2

Cari Creator ID

Buka profil Roblox-mu. Angka di alamat roblox.com/users/ANGKA/profile adalah Creator ID. Untuk grup, pakai angka di alamat grup dan pilih tipe Group.

3

Buat API Key

Buka create.roblox.com/dashboard/credentials, lalu Create API Key. Beri nama, di Access Permissions tambahkan API System Assets dengan izin Read dan Write, pilih akun pemilik, di Security isi 0.0.0.0/0, simpan, lalu salin key-nya.

4

Isi Settings

Buka Settings, isi Creator ID dan API key, lalu tekan Cek & Simpan API Key. Tombol preview audio butuh izin Asset Delivery pada key; kalau gagal, upload tetap normal.

5

Upload Audio

Pilih file (boleh banyak), potong bagian yang dipakai, atur speed dan pitch, lalu Upload & Publish. Salin Asset ID hasilnya.

6

Animasi dan Model

Export dari Roblox Studio sebagai .rbxm, lalu upload di menu masing-masing. Dua fitur ini butuh kode akses dari WhatsApp.

7

Cek Status

Tempel Asset ID di menu Cek Status untuk melihat disetujui, direview, atau ditolak.

8

Pakai di Roblox

Gunakan format rbxassetid://ID pada Sound atau Animation di Roblox Studio. Audio biasanya hanya bisa dipakai di game milik creator yang sama, kecuali kamu memberi izin.
